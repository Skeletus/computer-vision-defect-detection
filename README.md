# Surface Defect Detection Using Computer Vision

Computer vision project for the detection of surface defects in industrial images.

The goal of this project is to explore the application of object detection techniques for identifying different types of defects present on material surfaces.

## Initial Objectives

- Explore and understand the image dataset.
- Analyze the available defect categories.
- Prepare the data for computer vision experiments.
- Train and evaluate an object detection model.

## Technologies

- Python
- OpenCV
- PyTorch
- YOLO
